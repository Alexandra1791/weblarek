# Интернет-магазин «Web-Larёk»
«Web-Larёk» — это интернет-магазин с товарами для веб-разработчиков, где пользователи могут просматривать товары, добавлять их в корзину и оформлять заказы. Сайт предоставляет удобный интерфейс с модальными окнами для просмотра деталей товаров, управления корзиной и выбора способа оплаты, обеспечивая полный цикл покупки с отправкой заказов на сервер.

## Архитектура приложения

Код приложения разделен на слои согласно парадигме MVP (Model-View-Presenter), которая обеспечивает четкое разделение ответственности между классами слоев Model и View. Каждый слой несет свой смысл и ответственность:

Model - слой данных, отвечает за хранение и изменение данных.  
View - слой представления, отвечает за отображение данных на странице.  
Presenter - презентер содержит основную логику приложения и  отвечает за связь представления и данных.

Взаимодействие между классами обеспечивается использованием событийно-ориентированного подхода. Модели и Представления генерируют события при изменении данных или взаимодействии пользователя с приложением, а Презентер обрабатывает эти события используя методы как Моделей, так и Представлений.

### Базовый код

#### Класс Component
Является базовым классом для всех компонентов интерфейса.
Класс является дженериком и принимает в переменной `T` тип данных, которые могут быть переданы в метод `render` для отображения.

Конструктор:  
`constructor(container: HTMLElement)` - принимает ссылку на DOM элемент за отображение, которого он отвечает.

Поля класса:  
`container: HTMLElement` - поле для хранения корневого DOM элемента компонента.

Методы класса:  
`render(data?: Partial<T>): HTMLElement` - Главный метод класса. Он принимает данные, которые необходимо отобразить в интерфейсе, записывает эти данные в поля класса и возвращает ссылку на DOM-элемент. Предполагается, что в классах, которые будут наследоваться от `Component` будут реализованы сеттеры для полей с данными, которые будут вызываться в момент вызова `render` и записывать данные в необходимые DOM элементы.  
`setImage(element: HTMLImageElement, src: string, alt?: string): void` - утилитарный метод для модификации DOM-элементов `<img>`


#### Класс Api
Содержит в себе базовую логику отправки запросов.

Конструктор:  
`constructor(baseUrl: string, options: RequestInit = {})` - В конструктор передается базовый адрес сервера и опциональный объект с заголовками запросов.

Поля класса:  
`baseUrl: string` - базовый адрес сервера  
`options: RequestInit` - объект с заголовками, которые будут использованы для запросов.

Методы:  
`get(uri: string): Promise<object>` - выполняет GET запрос на переданный в параметрах ендпоинт и возвращает промис с объектом, которым ответил сервер  
`post(uri: string, data: object, method: ApiPostMethods = 'POST'): Promise<object>` - принимает объект с данными, которые будут переданы в JSON в теле запроса, и отправляет эти данные на ендпоинт переданный как параметр при вызове метода. По умолчанию выполняется `POST` запрос, но метод запроса может быть переопределен заданием третьего параметра при вызове.  
`handleResponse(response: Response): Promise<object>` - защищенный метод проверяющий ответ сервера на корректность и возвращающий объект с данными полученный от сервера или отклоненный промис, в случае некорректных данных.

#### Класс EventEmitter
Брокер событий реализует паттерн "Наблюдатель", позволяющий отправлять события и подписываться на события, происходящие в системе. Класс используется для связи слоя данных и представления.

Конструктор класса не принимает параметров.

Поля класса:  
`_events: Map<string | RegExp, Set<Function>>)` -  хранит коллекцию подписок на события. Ключи коллекции - названия событий или регулярное выражение, значения - коллекция функций обработчиков, которые будут вызваны при срабатывании события.

Методы класса:  
`on<T extends object>(event: EventName, callback: (data: T) => void): void` - подписка на событие, принимает название события и функцию обработчик.  
`emit<T extends object>(event: string, data?: T): void` - инициализация события. При вызове события в метод передается название события и объект с данными, который будет использован как аргумент для вызова обработчика.  
`trigger<T extends object>(event: string, context?: Partial<T>): (data: T) => void` - возвращает функцию, при вызове которой инициализируется требуемое в параметрах событие с передачей в него данных из второго параметра.

### Данные
В этом разделе описаны интерфейсы и типы данных. 

#### Интерфейс IProduct
Описывает структуру данных одной карточки товара, получаемой с сервера.
  interface IProduct {
  id: string;
  description: string;
  image: string;
  title: string;
  category: string;
  price: number | null;
}

#### Интерфейс IBuyer
Описывает структуру данных покупателя.
interface IBuyer {
  payment: TPayment;
  email: string;
  phone: string;
  address: string;
}

#### Типы

`type TPayment = 'card' | 'cash';` - описывает доступные способы оплаты заказа.
`type FormErrors = Partial<Record<keyof IBuyer, string>>;` - описывает структуру объекта ошибок валидации форм. Ключами являются поля формы, а значение - текст ошибки.

### Модели данных (Классы)
Классы этого слоя отвечают за хранение информации, ее изменение и предоставление бизнес-логики для других частей приложения.

#### Класс CatalogData (Каталог товаров)

Конструктор:
`constructor()` - создает пустой список товаров и закрывает просмотр карточек. Работает без настроек.

Поля класса:
`protected items: IProduct[]` - хранит массив всех товаров, доступных для покупки.
`protected preview: string | null` - хранит идентификатор (`id`) товара, выбранного для отображения в модальном окне.

Методы класса:
`setItems(product: IProduct[]): void` - берёт список товаров из интернета и сохраняет его в проект. Ничего не возвращает.
`getItems(): IProduct[]` - выдает сохраненный список товаров, чтобы показать его на главном экране. Возвращает список товаров.
`getProduct(productId: string): IProduct | null` -  находит один нужный товар в списке по его ID. Возвращает найденный товар(или ничего, если такого ID нет).
`setPreviewId(productId: string): void` - запоминает, на какой товар нажал пользователь, чтобы открыть его. Ничего не возвращает.
`getPreviewId(): string | null` - возвращает идентификатор (`id`) выбранного для просмотра товара.
`getPreviewProduct(): IProduct | null` - выдает тот самый товар, который пользователь выбрал для просмотра. Возвращает выбранный товар.

#### Класс BasketData (Корзина)
Класс отвечает за хранение товаров, которые покупатель отложил для покупки.

Конструктор:
`constructor()` — делает корзину изначально пустой. Работает без настроек.

Поля класса:
`protected items: IProduct[]` - список товаров, которые лежат в корзине.

Методы класса:
`getItems(): IProduct[]` - выдает список всех товаров, которые сейчас лежат в корзине.
`add(product: IProduct): void` - добавляет выбранный товар в корзину. Ничего не возвращает.
`remove(productId: string): void` - убирает товар из корзины по его ID. Ничего не возвращает.
`clear(): void` - полностью опустошает корзину. Ничего не возвращает.
`getTotal(): number` - считает общую стоимость всех товаров в корзине и возращает итоговую сумму.
`getCount(): number` - считает и возвращает общее количество товаров  в корзине.
`hasProduct(productId: string): boolean` - проверяет, лежит ли уже этот конкретный товар в корзине. Возвращает true/false.

#### Класс OrderData (Покупатель)
Класс собирает данные покупателя (адрес, телефон, почту, способ оплаты), проверяет их на ошибки и хранит до отправки заказа.

Конструктор
`constructor()` - создает чистую анкету покупателя, где еще ничего не заполнено.

Поля класса:
`protected buyer: IBuyer` - анкета с данными покупателя (оплата, адрес, телефон, email).

Методы класса:
`setField(field: keyof IBuyer, value: string): void` - сохраняет текст в конкретную строку анкеты, не стирая при этом остальные заполненные поля. Ничего не возвращает.
`getBuyerData(): IBuyer` - отдает всю заполненную анкету покупателя целиком.
`clear(): void` - полностью стирает всю анкету и сбрасывает список ошибок. Ничего не возвращает.
`validatedata(): FormErrors` - проверяет, чтобы ни одно поле в анкете не осталось пустым. Если находит пустое поле, возвращает текст ошибки для него.

### Слой коммуникации
Классы этого слоя отвечают за организацию взаимодействия между моделями данных приложения и внешним сервером.

#### Класс AppApi
Обеспечивает обмен данными с сервером для получения каталога товаров и отправки оформленных заказов.

Конструктор:
`constructor(baseApi: IApi)` - принимает объект, соответствующий интерфейсу `IApi`, для выполнения HTTP-запросов.

Методы класса:
`getProducts(): Promise<IProductResponse>` - выполняет GET-запрос к эндпоинту `/product/` для получения  полного объекта с массивом товаров с сервера. Возвращает промис с объектом, содержащим список товаром и их общее количество.
`postOrder(orderData: IOrderRequest): Promise<IOrderResult>` - выполняет POST-запрос к эндпоинту `/order/` для отправки данных о покупателе и выбранных товарах на сервер. Возвращает промис с подтверждением успешной покупки(ID заказа и итоговая сумма).

### Слой представления (View)
Классы этого слоя отвечают за отображение интерфейса и  обработку действий пользователя.

#### Класс Modal
Универсальное модальное окно

Конструктор:
`constructor(container: HTMLElement, protected events: IEvents)` - находит кнопку закрытия и контейнер контента, вешает слушатели закрытия по клику на крестик и оверлей.

Поля:
`protected closeButton: HTMLButtonElement` - кнопка закрытия модального окна.
`protected contentElement: HTMLElement;` - контейнер для отображения переданного содержимого.


Методы класса:
`set content(value: HTMLElement)` - заменяет содержимое модального окна.
`open(): void` - открывает модальное окно и генерирует событие `modal:open`.
`close(): void` - закрывает модальное окно, очищает контент и генерирует событие `modal:close`.
`render(data: IModalData): HTMLElement` - устанавливает контент и открывает модальное окно.

Генерируемые события:
`modal:open` - открытие модального окна.
`modal:close` - закрытие модального окна.

#### Класс Form
Базовый класс для всех форм в приложении. Отслеживает ввод данных в поля, управляет блокировкой кнопки отправки и выводит текст ошибок.

Конструктор:
`constructor(protected container: HTMLFormElement, protected events: IEvents)` -  принимает элемент формы и брокер событий. Находит кнопку отправки и блок ошибок, вешает слушатели событий `input` и `submit`.

Поля класса:
`protected submitButton: HTMLButtonElement` - кнопка отправки формы.
`protected errorsElement: HTMLElement` - элемент для вывода текста ошибок валидации.

Методы класса:
`protected onInputChange(field: keyof T, value:string):void` - генерирует событие об изменении конкретного поля формы.
`set valid(value: boolean)` - включает или отключает кнопку отправки формы.
`set errors(value: string)` - выводит текст ошибок валидации.
`render(state: Partial<T> & IFormState): HTMLFormElement` - обновляет состояние валидности, ошибки и значения полей формы.

Генерируемые события:
`${this.container.name}.${String(field)}:change` - изменение значения в поле формы.
`${this.container.name}:submit` - отправка формы.

#### Класс Card
Базовый класс для всех видов карточек товара. Выносит общий для всех шаблонов функционал отображения названия и цены.

Конструктор:
`constructor(container: HTMLElement)` - принимает DOM-элемент карточки и находит в нем элементы заголовка и цены.

Поля класса:
`protected titleElement: HTMLElement` - элемент отображения названия товара.
`protected priceElement: HTMLElement` - элемент отображения цены товара.

Методы класса:
`set title(value:string)` - устанавливает название товара.
`set price(value: number | null)` - устанавливает цену товара (если цена `null`, выводит "Бесценно").

#### Класс Header
Отвечает за отображение шапки сайта, кнопки корзины и счетчика добавленных в нее товаров. Наследуется от класса `Component`.

Конструктор:
`constructor(container: HTMLElement, protected events: IEvents)` - принимает контейнер шапки и брокер событий. Находит кнопку корзины и счетчик, устанавливает слушатель клика.

Поля класса:
`protected basketButton: HTMLButtonElement` - кнопка открытия корзины.
`protected counterElement: HTMLElement` - элемент счетчика товаров в корзине.

Методы класса:
`set counter(value: number)` - обновляет количество товаров на иконке корзины.

Генерируемые события:
`basket:open` - клик по кнопке корзины в шапке сайта.

#### Класс Gallery
Отвечает за отображение главного контейнера со списком карточек товаров на странице. Наследуется от класса `Component`.

Конструктор:
`constructor(container: HTMLElement)` - принимает DOM-элемент контейнера галереи.

Методы класса:

Конструктор:
`constructor(container: HTMLElement, actions?: ICardActions)` - принимает темплейт карточки и объект с колбэками. Находит элементы категории и изображения, вешает обработчик клика по карточке.

Поля класса:
`protected categoryElement: HTMLElement` - элемент отображения категории товара.
`protected imageElement: HTMLImageElement` - устанавливает изображения товара.

Методы класса:
`set category(value: string)` - устанавливает текст категории и применяет соответствующий CSS-класс фона.
`set image(value: string)` - элемент изображения товара.

Генерируемые события:
`card:select` (через переданный колбэк `onClick`) - клик по карточке товара в каталоге.

#### Класс CardPreview
Компонент подробной карточки товара для отображения в модальном окне при просмотре. Наследуется от класса `Card`.

Конструктор:
`constructor(container: HTMLElement, action?: ICardActions)` - принимает темплейт карточки превью и объект с колбэками. Находит элементы карточки и кнопку покупки/удаления, вешает слушатель клика на кнопку.

Поля класса:
`protected categoryElement: HTMLElement` - элемент отображения категории товаров.
`protected imageElement: HTMLImageElement` - элемент изображения товара.
`protected descriptionElement: HTMLElement` - элемент подробного описания товара.
`protected button: HTMLButtonElement` - кнопка добавления товара в корзину или удаления из нее.

Методы класса:
`set category(value: string)` - устанавливает текст категории и ее цветовой класс.
`set image(value: string)` - устанавливает изображение товара.
`set description(value: string)` - устанавливает текстовое описание товара.
`set buttonText(value: string)` - устанавливает текст на кнопке.

Генерируемые события:
`card:toggle` (через переданный колбэк `onClick`) - нажатие на кнопку покупки/удаления товара.

#### Класс CardBasket
Компонент компактной карточки товара для отображения в списке внутри корзины. Наследуется от класса `Card`.

Методы класса:

Генерируемые события:
`basket:remove` (через переданный колбэк `onClick`) - клик по кнопке удаления товара из корзины.

#### Класс Basket
Компонент отображения корзины с выбранными товарами и итоговой стоимостью. Наследуется от класса `Component`.

Конструктор:
`constructor(container: HTMLElement, protected events: IEvents)` - принимает темплейт корзины и брокер событий. Находит список товаров, итоговую сумму и кнопку оформления, устанавливает слушатель клика.

Поля класса:
`protected listElement: HTMLElement` - контейнер списка карточек товаров в корзине.
`protected totalElement: HTMLElement` - элемент отображения общей стоимости заказа.

Методы класса:

`order:open` - клик по кнопке "Оформить".

#### Класс OrderForm
Компонент первого шага оформления заказа (выбор способа оплаты и ввод адреса доставки). Наследуется от класса `Form`.

Конструктор:
`constructor(container: HTMLFormElement, events: IEvents)` - принимает элемент формы и брокер событий. Находит кнопки выбора способа оплаты и поле адреса, устанавливает слушатели клика на кнопке оплаты.

### Слой Презентер
Логика взаимодействия между слоем данных (Model) и слоем отображения (View). Презентер подписывается на события моделей и представлений, обеспечивая обновление интерфейса при изменении данных и обработку действий пользователя.

#### События моделей данных
`items:changed` - генерируется при обновлении списка товаров в `Catalogdata`. Презентер создает карточки каталога (`CardCatalog`) и передает их в `Gallery` для отрисовки.
`preview:changed` - генерируется при выборе товара для просмотра в `Catalogdata`. Презентер формирует карточку подробного описания (`CardPreview`), определяет состояние кнопки покупки и открывает ее в `Modal`.
`basket:changed` - генерируется при добавлении, удалении товаров или очистки `BasketData`. Презентер обновляет счетчик в `Header`, перерисовывает список товаров (`CardBasket`) и итоговую стоимость в `Basket`.
`order:changed` - генерируется при изменении данных покупателя или очистке в `OrderData`. Презентер запускает валидацию, обновляет значения полей, текст ошибок и доступность кнопок отправки в формах `OrderForm` и `ContactsForm`.

#### События слоя представления
`card:select` - клик по карточке товара в каталоге. Сохраняет идентификатор выбранного товара в `Catalogdata`.
`card:toggle` - клик по кнопке покупки или удаления в `CardPreview`. Добавляет товар в `BasketData` или удаляет его оттуда, после чего закрыввает модальное окно.
`basket:open` - клик по кнопке корзины в `Header`. ОТкрывает модальное окно `Modal` с содержимым компонента `Basket`.
`basket:remove` - клик по удаления позиции в `CardBasket`. Удаляет соответсвующий товар из `BasketData`.
`order:open` -клик по кнопке "Оформить" в `Basket`. Открывает в модальном окне первую форму заказа `OrderForm`.
`order.payment:change` / `order.address:change` - выбор способа оплаты или ввод адреса доставки в `OrderForm`. Сохраняет введенное значение `OrderData`.
`order:submit` - подтверждение первой формы оформления заказа. Открывает в модальном окне вторую форму заказа `ContactsForm`.
`contacts.email:change` / `contacts.phone:change` - ввод электронной почты или номера телефона в `ContactsForm`. Сохраняет введенное значение `OrderData`.
`contacts:submit` - отправка формы контактных данных. Отправляет сформированный заказ на сервер через `AppApi.postOrder()`, после успешного ответа очищает корзину и данные покупателя и открывает окно `Success`.
`modal:open` / `modal:close` - открытие и закрытие модального окна `Modal`. Блокирует и разблокирует прокрутку основной страницы.
